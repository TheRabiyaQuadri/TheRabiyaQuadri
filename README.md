### 🚀 Featured R&D Projects

**1. Autonomous Real-Time UAV Detection System** (`uav-detection-yolo`)  
An edge-optimized computer vision pipeline built to detect and isolate small-scale aerial intruders in cluttered environments.
* **Loss Tuning:** Integrated custom CIoU loss to improve bounding box regression for tiny objects.
* **Performance:** Optimized inference latency from ~45.2 ms (FP32 CPU) down to ~8.1 ms (FP16 Edge/GPU).

**2. Multimodal Autism Detection & Therapy Recommendation System** (`asd-multimodal-fusion-engine`)  
An end-to-end web and mobile application designed to assist in early Autism Spectrum Disorder (ASD) screening and personalized care.
* **Multimodal Architecture:** Fuses tabular screening questionnaire data (analyzed via scikit-learn classifiers like Decision Trees and Random Forests reaching up to ~81% accuracy) with deep learning video/image models (evaluating convolutional backbones such as ResNet101V2, ResNet50, and VGG19).
* **Smart Integration & Therapy Guidance:** Combines and averages predictions from both models for a reliable assessment, automatically generating personalized, ASQ score-based therapy recommendations.
