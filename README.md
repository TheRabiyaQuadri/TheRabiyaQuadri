## 🚀 Featured R&D Projects

### 1. [Autonomous Real-Time UAV Detection System](https://github.com/TheRabiyaQuadri/uav-detection-yolo)
*An edge-optimized computer vision pipeline designed to detect and isolate small-scale aerial intruders ($<32\times32$ pixels) under complex atmospheric clutter.*
- **Mathematical Rigor:** Custom CIoU loss integration to handle small bounding box regression penalties.
- **Hardware Performance:** Optimized from ~45.2 ms (FP32 CPU) down to ~8.1 ms (FP16 Edge/GPU) inference latency.
- **End-to-End Reproducibility:** Features structured training scripts (`Custom train YOLOV8.ipynb`), dataset configurations, and hardware profiling metrics.
